# OBSIDION — Evaluator Release 001

OBSIDION is an evidence-driven software intelligence system designed to
analyze software structure, build evidence, architectural relationships,
and engineering decision surfaces.

## Evaluator Release

This is the first controlled evaluator package.

The objective is simple:

**Give OBSIDION a software system and see what it discovers.**

The evaluator is intended to demonstrate analysis capabilities including:

- build evidence analysis
- architecture discovery
- architectural relationship analysis
- engineering decision generation
- impact prioritization
- evidence-backed reporting
